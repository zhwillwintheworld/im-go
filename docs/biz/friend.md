# 好友领域

## 领域职责

好友领域负责好友请求、接受、拒绝、删除好友和好友列表查询。

## 好友请求

发送好友请求时需要校验：
- 不能添加自己。
- 目标用户必须存在。
- 双方当前不能已是好友。
- 不能存在同方向待处理请求。

好友请求状态：
- `0`：待处理
- `1`：已同意
- `2`：已拒绝

## 接受好友

接受请求时需要校验：
- 请求存在且未删除。
- 请求接收者是当前用户。
- 请求状态仍为待处理。

接受后创建双向好友关系。

## 拒绝好友

拒绝请求时只更新请求状态，不创建好友关系。

## 删除好友

删除好友关系时双向逻辑删除。

## 数据规则

- 不使用数据库外键。
- 好友关系通过 `friends(user_id, friend_id)` 唯一约束避免重复。
- 查询好友列表时需要过滤 `deleted = 0`。
- 返回给前端的 ID 必须以 string 传输，避免 JS 精度丢失。

## 低时延要求

- 好友接口不是消息主链路，但仍应保持数据库查询简单。
- 好友列表可后续缓存，但缓存失效必须明确。
- 不应把好友校验放入实时消息发送热路径，除非有明确需求。
